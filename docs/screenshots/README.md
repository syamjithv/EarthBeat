# Screenshot capture guide

Automated browser navigation was unavailable during the final documentation
pass, so this directory intentionally contains no fake screenshots.

Capture these real views from a running local app and save them here:

1. `earthbeat-hero.png` — landing view showing the EarthBeat headline and
   primary action.
2. `earthbeat-studio.png` — studio view showing the NASA contextual visual,
   anomaly chart, timeline, and controls after NASA data loads.
3. `earthbeat-method.png` — methodology and sources sections.

Recommended command:

```bash
npm run dev -- --host 127.0.0.1
```

Use a browser screenshot tool or a normal browser window at
`http://127.0.0.1:5173/`. Do not label a placeholder as a product screenshot.
